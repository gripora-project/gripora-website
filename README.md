# Gripora Website

The source of [gripora.org](https://gripora.org), the home page of
[Gripora](https://github.com/gripora-project/gripora-firmware), open-source stability-control
firmware for RC cars.

The page is one static file, `index.html`, with its styles inline. There is no build step.

## Branding

`branding/` holds the interim Gripora logo set, and the other repositories link to it:

| File | Use |
| --- | --- |
| `gripora_logo_dark.svg` / `gripora_logo_white.svg` | Icon and wordmark, for light / dark backgrounds |
| `gripora_wordmark_dark.svg` / `gripora_wordmark_white.svg` | Wordmark only |
| `gripora_icon.svg` / `gripora_icon_white.svg` | The tyre "G" mark on its own |
| `gripora_icon_tile.svg` | App icon / favicon (mark on a dark rounded tile) |
| `favicon.ico`, `png/` | Rendered PNG sizes and the favicon |

Colours: orange `#FF5F1F`, ink `#16181D`, white `#FFFFFF`.

The SVGs are generated by `branding/generate-logo.mjs` (plain Node, no dependencies):

```
node branding/generate-logo.mjs branding
```

The PNGs and `favicon.ico` were rendered from the SVGs with `@resvg/resvg-js` and `png-to-ico`.

## Preview

Open `index.html` in a browser, or serve the folder:

```
python -m http.server 8000
```

## Deployment

Pushing to `master` publishes the folder to the `gh-pages` branch through
`.github/workflows/deploy-gh-pages.yml`. The `CNAME` file sets the custom domain, `gripora.org`.
